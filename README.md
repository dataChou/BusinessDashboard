# 🐾 宠物医院经营分析看板

一个为宠物医院老板量身打造的经营分析工具，帮助识别高价值客户、盈利项目、医生绩效和流失风险。支持 **Excel 静态报告** 和 **交互式网页看板**，数据可模拟或替换为真实数据。

## 📁 项目文件

| 文件 | 说明 |
|------|------|
| `pet_hospital_data.csv` | 模拟原始数据（4,000客户，38,150订单，营收1307万） |
| `宠物医院经营分析看板_最终版.xlsx` | Excel 看板（含Dashboard、流失列表、原始数据抽样） |
| `app.py` | **Streamlit 交互式看板**（推荐使用） |
| `app.R` | R Shiny 看板（备选，功能类似） |
| `requirements.txt` | Python 依赖清单 |
| `分析摘要.docx` | 一页核心结论（可自行生成） |
| `经营建议报告.docx` | 详细经营改进建议（可自行生成） |

## 🚀 快速开始

### 1. Excel 看板（最简单）
直接双击打开 `宠物医院经营看板_最终版.xlsx`，查看：
- KPI总览（客户数、营收、流失率等）
- 客户分层饼图
- 服务项目营收排行
- 医生接诊量排行
- 流失客户列表
- 原始数据抽样

### 2. Streamlit 网页看板（推荐，交互式）
#### 点击云端
https://businessdashboard-datachou.streamlit.app/

#### R Shiny 看板（备选）
install.packages(c("shiny", "shinydashboard", "dplyr", "plotly", "readr", "DT", "shinyWidgets"))
shiny::runApp("app.R")

### 📊 看板功能
全局筛选：按医生、服务项目筛选，所有图表联动
KPI卡片：总客户数、总营收、流失率、客单价、总订单数
客户分层：高价值客户（≤30天）、活跃客户（≤90天）、沉睡客户（≤180天）、流失客户（>180天）
服务项目盈利：总金额、订单数、客单价、金额占比
医生绩效：接诊量、总业绩、客单价
流失客户预警：列表展示超过6个月未消费的客户（可搜索、排序）
月度趋势：营收与订单数双轴图

### 📝 业务假设
流失定义：超过180天未消费
高价值客户：最近30天有消费
服务项目价格区间：
疫苗：80-150元
绝育：300-600元
看病：200-800元
体检：150-350元
洗护：100-250元
